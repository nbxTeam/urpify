# よくある質問

## スキャンでプロジェクトは変更されますか？

いいえ。スキャンはファイルを読むだけです。変更を行うのは、そう明示している移行ウィンドウのステップと、シェーダーパネルの
「変換」ボタンだけで、どちらも必ず先にバックアップを取ります。

## プロジェクトのどれくらいが変換されますか？

何かを変更する前に、スキャンが教えてくれます：概要は壊れたアセットを誰が直すかで数えます。
開発者が見ていないシェーダーでの独立したテストで Urpify が変換できたものは、製品ページに記載しています。

## 移行を取り消せますか？

はい。**すべてロールバック** は、移行が変更したファイルをすべて元に戻し、移行が作ったファイルをバックアップに移します。
移行後に自分で変更したファイルと、ステップの間に現れたファイルはそのまま残り、一覧表示されます。中断したステップも、
完了したステップと同じようにロールバックされます。それでも、始める前にプロジェクトをコミットしてください：最も信頼
できるのはコミットです。

## Pro は必要ですか？

無料パッケージは、壊れるものをすべて見つけ、Unity のコンバーターを確実に実行し、Unity のコンバーターの誤りを直し、
移行前後のシーンを比較し、ロールバックします。Pro は無料パッケージにできないもの、つまり独自シェーダー、画像エフェクト、
カメラスクリプト、コマンドバッファー、プロジェクターを変換します。購入前に、壊れたアセットのうち Pro が必要なものの数を
概要で確認できます。

## Urpify はシェーダーのコードを書き換えますか？

配線だけです。作者の関数（`surf`、`vert`、`frag`、ライティング関数、ヘルパー）はそのままコピーされます。変わるのは、
シェーダーがライト、影、深度、画面の画像、行列をどう受け取るかです。Built-in の名前は Urpify の互換ライブラリによって
引き続き使えます。シェーダー名とプロパティ名はそのままなので、マテリアルの値は保たれます。

## 変換したシェーダーの見た目がおかしい場合は？

変換したシェーダーはすべて、自分のマテリアルを付けた球で Built-in と URP の両方に描画されます。違いがあれば `要確認` に
なり、画像の組は `Urpify/Reports/self-check/` に置かれます。シェーダーパネルで開いてください：プレビュータブは Built-in と
URP を並べて表示し、コードタブはすべての変更を理由付きで表示します。そこで結果を編集して再コンパイルするか、移行とともに
シェーダーをロールバックできます。

## 自分の Unity のバージョンで使えますか？

Unity 2022.3 LTS、6000.0 LTS、6000.3 LTS、6000.5、6000.6 でテスト済みです。6000.1、6000.2、6000.4 は未テストです。[Unity と URP のバージョン](urp-version-matrix.md) を参照してください。

## CI で使えますか？

はい。どのステップもコマンドラインから実行でき、JSON の結果を書きます。[コマンドライン](cli.md) を参照してください。

## 「Built-in 対応を残す」はビルドを大きくしますか？

少しだけです。テスト環境（Unity 6.5、Mono）では、ゲームデータは Built-in で 32.5 MB、URP 専用シェーダーの URP で 38.2 MB、
両パイプライン用シェーダーで 38.5 MB でした：0.34 MB、つまり 0.9 % の増加です。

## 変換した画像エフェクトやプロジェクターは URP で重くなりますか？

Urpify のレンダラー機能を通じて実行され、同じ描画呼び出しを URP のフレームに記録します。プロジェクターは小さなシーンで
1 フレームあたり約 0.02 ms、可視レンダラー 5000 個では約 2.2 ms です。ビルドしたプレイヤーでも、Mono と IL2CPP のどちらの
ビルドでもエフェクトは保たれます。

## 「レポートを送信」は何を送りますか？

「送信」を押すまで何も送りません。レポート > レポートを送信... は、選んだシェーダー、その include ファイル、検出結果、
Unity・URP・Urpify のバージョン、コンパイラーエラー、そして入力した場合はコメントと連絡先をまとめます。送信前に、
ウィンドウはすべてのファイルを一覧表示します。**送信** はアーカイブをサポート窓口にアップロードし、**zip で保存** は
自分のマシンに保存します。ファイルはコンバーターに足りないものを知るためだけに使い、その後削除します。これは Urpify で
唯一のネットワーク呼び出しです。送信は 1 分に 1 回までです。

## Urpify で変換したシェーダーを販売できますか？

はい、それぞれのライセンスに従って販売できます。[変換したシェーダーの再配布](../license-redistribution.md)（英語）を
参照してください。ヘッダーに非商用ライセンスが書かれたシェーダーはそのライセンスのままです。シェーダーパネルには
ライセンスの行が表示されます。

## スキャンで「移行前からプロジェクトが壊れていた」と出るのはなぜですか？

実際に壊れていたからです：Built-in でコンパイルできないシェーダー、コンパイルできないスクリプト、プロジェクトにない
include ファイル、プロジェクトにないマテリアル。移行では直らないので、Urpify はこれらを別に表示します。まずこれらを直し、
もう一度スキャンしてください。

## URP をロールバックした後、シェーダーが一度だけ include エラーを出すのはなぜですか？

URP を使っていたプロジェクトから URP を外した後（ロールバックまたは手動で戻した場合）、最初のエディターセッションでは、
「Built-in 対応を残す」で作ったシェーダーの URP 用 SubShader がまだコンパイルされ、`Library/Artifacts` に残ったインポート
結果のせいで include エラーが記録されることがあります。2 回目のセッションでは消えます。これはシェーダーファイルではなく
Unity のインポートの挙動です：URP を一度も使っていないプロジェクトではエラーは出ません。プロジェクトをもう一度開くか、
Assets > Reimport All を実行してください。

## ウィンドウが別の言語で表示されます。

Project Settings > Urpify > 個人用 > 言語 で変更します。既定ではエディターの言語に従い、Urpify にその言語がない場合は英語
を使います。
