# 設定

Project Settings > **Urpify**、または Urpify ウィンドウの **設定** ボタンから開きます。

チームの設定は `ProjectSettings/UrpifySettings.asset` に保存されます。このファイルをコミットすれば、チーム全員が同じ
ように変換します。個人の設定は `UserSettings/Urpify.json` に保存され、自分のマシンに残ります。

## 変換（チーム）

Pro のコンバーターが何を書き出すかを決める設定です。

| 設定 | 値 | 既定値 | 内容 |
|---|---|---|---|
| 出力 | 元のファイルを置き換える、コピーを書き出す、Built-in 対応を残す | 元のファイルを置き換える | **元のファイルを置き換える**：シェーダーファイルは URP 専用になり、元のファイルはバックアップに残ります。**コピーを書き出す**：URP のシェーダーを元のファイルの隣に `Name_URP.shader`（シェーダー名 `Name (URP)`）として書き出し、マテリアルをそちらに切り替えます。元のファイルは残ります。**Built-in 対応を残す**：両方のパイプライン用の 1 つのファイル。元の SubShader は Built-in 用に残り、その前に URP の SubShader が追加されます。 |
| GrabPass のソース | Opaque Texture、透明オブジェクトの後 | Opaque Texture | **Opaque Texture**：変換した GrabPass は、透明オブジェクトの前に取った URP の画面コピーを読むため、屈折に透明オブジェクトは映りません。**透明オブジェクトの後**：Urpify のレンダラー機能が透明オブジェクトの後に画面をコピーし（Built-in の GrabPass と同じ）、その後で GrabPass を持つオブジェクトを描画します。1 フレームあたり画面コピーが 1 回増えます。 |
| 画面エフェクトの挿入位置 | ポストプロセスの後、ポストプロセスの前、不透明オブジェクトの後 | ポストプロセスの後 | 変換した `OnRenderImage` エフェクトを URP のフレームのどこで実行するか。`[ImageEffectOpaque]` 付きのエフェクトは、Built-in と同じく常にスカイの後に実行されます。 |
| 影 | 元と同じ、常に、しない | 元と同じ | 変換したサーフェスシェーダーが影を落とし、受けるかどうか。 |
| SRP Batcher | オン、オフ | オン | マテリアルプロパティを `UnityPerMaterial` バッファーに入れ、URP の SRP Batcher が変換したシェーダーをまとめられるようにします。独自の `UnityPerMaterial` を宣言しているシェーダーはそれを保ちます。安全に移せないプロパティは注記付きで外に残ります。 |

## 比較（チーム）

| 設定 | 既定値 | 内容 |
|---|---|---|
| キャプチャのサイズ | Game ビュー | キャプチャする各フレームのサイズ：Game ビューのサイズ（解像度に依存するエフェクトも見たとおりになります）か、カスタム。コマンドラインでは `-urpifyWidth` と `-urpifyHeight` を使います。 |
| キャプチャの幅、キャプチャの高さ | 960 × 540 | キャプチャのサイズがカスタムのとき、および Game ビューがないときのサイズ。 |
| キャプチャ前のフレーム数 | 30 | 各キャプチャの前に固定タイムステップで再生するフレーム数。アニメーションやパーティクルが移行前後で同じ状態になるようにします。 |
| シーン | Build Settings | 移行前をキャプチャと移行後をキャプチャで使うシーン：Build Settings のシーン、`Assets` 内のすべてのシーン、または一覧。 |
| シーンのパス | 空 | 選択したシーンの場合：セミコロン区切りのパス。例：`Assets/Scenes/Main.unity;Assets/Scenes/Menu.unity`。 |

「新たなピンク」「変化あり」「同じ」のしきい値は、Unity 自身の Standard から URP Lit への変換で調整されており、どの
プロジェクトにも当てはまります：フレームの 0.02 % を超える新しいピンクの領域は「新たなピンク」、Standard → URP Lit が
生む以上の変化ピクセル、または 1 つの大きな変化領域は「変化あり」です。

各シーンには **Migration Viewpoint** を置けます：空の GameObject に `MigrationViewpoint` コンポーネントを追加すると、
メインカメラに加えてその位置と向きからもキャプチャします。ビューポイントは独自の視野角とファークリップ面を持てます。
EditorOnly タグが付いているので、ビルドには含まれません。

## 個人用

| 設定 | 値 | 既定値 | 内容 |
|---|---|---|---|
| 言語 | エディターの言語、または 8 言語のいずれか | エディターの言語 | Urpify のウィンドウの言語。「エディターの言語」は Preferences > Languages に従い、その言語がなければ英語を使います。 |
| Built-in のプレビュー | ライブ、キャプチャから | ライブ | **ライブ** は Built-in のプレビューを描画する間だけレンダーパイプラインをオフにして戻します。1 回の呼び出しの中で行い、Play Mode 中やインポート・コンパイル中には行いません。**キャプチャから** は代わりにシーンのキャプチャを表示します。ライブプレビューが失敗した場合や、パイプラインの設定が正確に戻らなかった場合、Urpify は自動で「キャプチャから」に切り替えて知らせます。 |
| Project ウィンドウのオーバーレイ | オン、オフ | オン | 前回のスキャンで壊れていると判定したアセットに付く小さな印。 |

## 1 回の実行だけの上書き

コマンドラインでは、出力（`-urpifyShaderOutput`）と GrabPass のソース（`-urpifyGrabPass`）を 1 回の実行だけ上書き
できます。[コマンドライン](cli.md) を参照してください。
