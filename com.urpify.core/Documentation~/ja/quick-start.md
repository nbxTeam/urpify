# クイックスタート

スキャン、移行、比較という全体の流れを 5 分で行います。まずデモシーンで試し、次に自分のプロジェクトのコピーで試して
ください。

## 1. インストール

まだ Built-in Render Pipeline を使っているプロジェクトに、Urpify と、お持ちであれば Urpify Pro をインストールします。

- **Package Manager：** `+` > Add package from disk で `com.urpify.core` の `package.json`、続いて `com.urpify.pro` の
  ものを選びます。
- **`.unitypackage`：** Assets > Import Package > Custom Package で Urpify、続いて Urpify Pro をインポートします。

移行の前にプロジェクトをバージョン管理にコミットしてください。Urpify は変更するファイルをすべてバックアップしますが、
最も安全な復元ポイントはコミットです。

## 2. デモを開く（任意）

Help > Urpify > **Import Demo**、または空の Urpify ウィンドウの **デモをインポート** を実行します。デモは `Assets/Samples/Urpify/1.0.0/Demo` に入り、
そのシーンが開きます。Package Manager でインストールした場合は、Package Manager > Urpify > Samples > **Demo** > Import でも同じです。
シーンには URP で壊れる構成要素ごとにブースがあります：サーフェスシェーダー、ライティングありの vert/frag シェーダー、
GrabPass のガラス、深度を読む水、プロジェクター、スクリプトで描画する鏡、コードで作るマテリアル、Standard Transparent
モードのガラス。各ブースに Migration Viewpoint があるので、比較ではそれぞれを近くから確認できます。

## 3. スキャン

Window > Rendering > **Urpify** を開き、**プロジェクトをスキャン** を選びます。

スキャンはファイルを読むだけです。左のリストには、URP で壊れるシェーダー、スクリプト、マテリアル、シーン、設定が種類ごと
に表示されます。各行にはアイコンがあります。

- 塗りつぶした四角：ピンクになる
- 塗りつぶした三角：エラーなしで壊れる（ポータルが壁になる、水の泡が消える、エフェクトが消える）
- 塗りつぶしたひし形：見た目が変わる
- 輪：見た目の変化なし

行を選ぶと、何が壊れるか、なぜか、誰が直すかが表示されます。シェーダーはシェーダーパネルで開き、変換前後のコードと、
Built-in と URP のプレビューを並べて表示します。

## 4. 移行

**移行...** を選びます。ウィンドウにステップが並びます。

1. **スキャン**：同じ読み取り専用のスキャン。
2. **バックアップ**：プロジェクトのアセット、設定、パッケージ一覧を `Urpify/Backup` にコピーします。
3. **移行前をキャプチャ**：各シーンを Play Mode で再生し、メインカメラとすべての Migration Viewpoint のフレームを保存
   します。
4. **URP をインストール**：エディターに対応する URP のバージョンを追加します。
5. **Unity のコンバーターを実行**：Unity の Render Pipeline Converter を、確実に動かすために Urpify が必要とする回避策
   付きで実行します。
6. **Urpify のコンバーター**：Unity のコンバーターが壊れたまま残すものを直します。Pro ではシェーダー、スクリプト、
   コンポーネントも変換します。
7. **移行後をキャプチャして比較**：URP で同じフレームを撮り、移行前のフレームと比較します。
8. **まとめ**：最終レポート。

**すべて実行** を選びます。各ステップは個別にも実行でき、それぞれロールバックできます：ステップの **ここまで
ロールバック**、または **すべてロールバック**。

## 5. 比較

**シーンを比較** を選びます。各シーンは移行前後のフレームを、間のスライダーとともに表示します。**差分を表示** は変化した
ピクセルに印を付けます：赤いほど変化が大きいことを示します。**変化ありのみ** は同じに見えるシーンを隠します。

メインウィンドウでは、シーンに 2 つの判定があります：スキャンによる **静的** と、フレームによる **観測** です。ピンクの
オブジェクトがどのキャプチャフレームにも映っていないことがあるため、静的な判定が観測より悪くなることがあります。近くで
確認したい場所に Migration Viewpoint（`MigrationViewpoint` コンポーネントを付けた空の GameObject）を追加し、もう一度
キャプチャしてください。

## 6. 完了、またはロールバック

**レポート** > HTML をエクスポート で、チームに送れるレポートを作れます。結果が気に入らなければ、**すべてロールバック**
で移行が変更したファイルをすべて元に戻し、移行が作ったファイルをバックアップに移します。ステップの間に現れたファイルは
決して触れないので、自分の作業は残ります。
ウィンドウからロールバックすると、Unity はすぐに再起動し、ディスク上のプロジェクトを読み込み直します。
