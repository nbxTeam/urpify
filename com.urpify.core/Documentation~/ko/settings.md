# 설정

Project Settings > **Urpify**, 또는 Urpify 창의 **설정** 버튼에서 엽니다.

팀 설정은 `ProjectSettings/UrpifySettings.asset`에 저장됩니다. 이 파일을 커밋하면 팀 전체가 같은 방식으로 변환합니다. 개인
설정은 `UserSettings/Urpify.json`에 저장되며 내 컴퓨터에만 남습니다.

## 변환(팀)

Pro 컨버터가 무엇을 쓸지 정하는 설정입니다.

| 설정 | 값 | 기본값 | 하는 일 |
|---|---|---|---|
| 출력 | 원본 교체, 사본 작성, Built-in 지원 유지 | 원본 교체 | **원본 교체**: 셰이더 파일이 URP 전용이 되고, 원본은 백업에 남습니다. **사본 작성**: URP 셰이더를 원본 옆에 `Name_URP.shader`(셰이더 이름 `Name (URP)`)로 쓰고, 머티리얼을 그쪽으로 바꿉니다. 원본은 남습니다. **Built-in 지원 유지**: 두 파이프라인용 파일 하나. 원래 SubShader는 Built-in용으로 남고, 그 앞에 URP SubShader가 추가됩니다. |
| GrabPass 소스 | Opaque Texture, 투명 오브젝트 후 | Opaque Texture | **Opaque Texture**: 변환된 GrabPass가 투명 오브젝트 전에 찍은 URP의 화면 사본을 읽으므로, 굴절에 투명 오브젝트가 보이지 않습니다. **투명 오브젝트 후**: Urpify의 렌더러 기능이 투명 오브젝트 후에 화면을 복사하고(Built-in의 GrabPass와 같음), 그 다음 GrabPass가 있는 오브젝트를 그립니다. 프레임마다 화면 복사가 한 번 늘어납니다. |
| 화면 효과 삽입 위치 | 포스트 프로세싱 후, 포스트 프로세싱 전, 불투명 오브젝트 후 | 포스트 프로세싱 후 | 변환된 `OnRenderImage` 효과를 URP 프레임의 어디에서 실행할지. `[ImageEffectOpaque]`가 붙은 효과는 Built-in과 마찬가지로 항상 하늘 다음에 실행됩니다. |
| 그림자 | 원본과 같게, 항상, 안 함 | 원본과 같게 | 변환된 서피스 셰이더가 그림자를 드리우고 받는지 여부. |
| SRP Batcher | 켜기, 끄기 | 켜기 | 머티리얼 프로퍼티를 `UnityPerMaterial` 버퍼에 넣어, URP의 SRP Batcher가 변환된 셰이더를 묶을 수 있게 합니다. 자체 `UnityPerMaterial`을 선언한 셰이더는 그것을 유지하고, 안전하게 옮길 수 없는 프로퍼티는 메모와 함께 밖에 남습니다. |

## 비교(팀)

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 캡처 크기 | Game 뷰 | 캡처하는 각 프레임의 크기: Game 뷰 크기(해상도에 따라 달라지는 효과도 보이는 그대로 나옵니다) 또는 사용자 지정. 명령줄은 `-urpifyWidth`와 `-urpifyHeight`를 씁니다. |
| 캡처 너비, 캡처 높이 | 960 × 540 | 캡처 크기가 사용자 지정일 때와 Game 뷰가 없을 때의 크기. |
| 캡처 전 프레임 수 | 30 | 각 캡처 전에 고정 시간 간격으로 재생하는 프레임 수. 애니메이션과 파티클이 전후로 같은 상태가 되게 합니다. |
| 씬 | Build Settings | 이전 캡처와 이후 캡처에 쓰는 씬: Build Settings의 씬, `Assets` 아래의 모든 씬, 또는 목록. |
| 씬 경로 | 비어 있음 | 선택한 씬일 때: 세미콜론으로 구분한 경로. 예: `Assets/Scenes/Main.unity;Assets/Scenes/Menu.unity`. |

"새 분홍색", "변경됨", "같음"의 임계값은 Unity 자체의 Standard에서 URP Lit로의 변환을 기준으로 보정되어 있으며 어떤
프로젝트에도 적용됩니다: 프레임의 0.02 %를 넘는 새 분홍색 영역은 "새 분홍색", Standard → URP Lit가 만드는 것보다 많은 픽셀
변화나 하나의 큰 변화 영역은 "변경됨"입니다.

각 씬에는 **Migration Viewpoint**를 둘 수 있습니다: 빈 GameObject에 `MigrationViewpoint` 컴포넌트를 추가하면, 메인 카메라와
함께 그 위치와 방향에서도 캡처합니다. 뷰포인트는 자체 시야각과 원거리 클리핑 평면을 가질 수 있습니다. EditorOnly 태그가
붙어 있어 빌드에는 들어가지 않습니다.

## 개인

| 설정 | 값 | 기본값 | 하는 일 |
|---|---|---|---|
| 언어 | 에디터 언어, 또는 8개 언어 중 하나 | 에디터 언어 | Urpify 창의 언어. "에디터 언어"는 Preferences > Languages를 따르고, 그 언어가 없으면 영어를 씁니다. |
| Built-in 미리 보기 | 실시간, 캡처에서 | 실시간 | **실시간**은 Built-in 미리 보기를 렌더링하는 동안만 렌더 파이프라인을 끄고 다시 켜며, 한 번의 호출 안에서 처리합니다. Play Mode 중이나 가져오기·컴파일 중에는 하지 않습니다. **캡처에서**는 대신 씬 캡처를 보여 줍니다. 실시간 미리 보기가 실패하거나 파이프라인 설정이 정확히 돌아오지 않으면, Urpify가 스스로 "캡처에서"로 바꾸고 알려 줍니다. |
| Project 창 오버레이 | 켜기, 끄기 | 켜기 | 마지막 스캔에서 깨진 것으로 판정한 에셋에 붙는 작은 표시. |

## 한 번의 실행만 덮어쓰기

명령줄에서 출력(`-urpifyShaderOutput`)과 GrabPass 소스(`-urpifyGrabPass`)를 한 번의 실행에 대해서만 덮어쓸 수 있습니다.
[명령줄](cli.md)을 참고하세요.
