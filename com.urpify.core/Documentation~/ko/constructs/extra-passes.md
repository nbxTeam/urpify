# 추가 패스: 외곽선, 셸, 레이어

![부스 S12: 반전 헐 외곽선 패스가 있는 툰 셰이더](../../images/S12.jpg)

*부스 S12: 직접 쓴 외곽선 패스가 있는 툰 서피스 셰이더. Unity 컨버터만 거치면 분홍색 구 주위에 외곽선 하나만 남습니다.*

## 무엇이 깨지는가

URP는 오브젝트 하나에 대해 SubShader의 패스를 최대 두 개까지만 그립니다: `SRPDefaultUnlit` 하나와 `UniversalForward` 하나를
이 순서로 그립니다. Built-in은 모든 패스를 그립니다. 라이팅 패스 옆에 외곽선 패스가 있는 셰이더, 털 셸, 해칭 레이어, LightMode
태그가 없는 두 패스는 그중 하나만 남으며, 대개 아무 알림도 없습니다.

발견 사항: "서피스 프로그램 옆의 추가 패스"(`SHADER.SURFACE.EXTRA_PASS`), "LightMode가 없는 패스: N"
(`SHADER.PASS.MULTIPLE_UNTAGGED`).

## Urpify가 하는 일(Pro)

- **그리는 패스가 두 개:** 첫 번째를 `SRPDefaultUnlit`, 두 번째를 `UniversalForward`로 만들어 Built-in의 그리기 순서를
  유지합니다. URP 14와 17에서 확인했습니다.
- **그리는 패스가 세 개 이상:** 세 번째부터 `UrpifyPass3`, `UrpifyPass4` 등의 태그를 붙입니다. Urpify의 Built-in Camera
  Hooks 렌더러 기능이 URP의 불투명 또는 투명 오브젝트 다음에, 각 오브젝트의 패스를 순서대로 그립니다. SubShader당 그리는
  패스는 최대 32개입니다.
- **서피스 프로그램 옆에 직접 쓴 패스**는 그대로 남고, vert/frag 규칙으로 변환됩니다.
- `Graphics.Blit`이 그리는 이미지 효과 셰이더에는 태그를 붙이지 않습니다: 패스는 인덱스로 선택됩니다.

렌더러 기능은 "Urpify 컨버터" 단계에서 그것이 필요한 모든 URP 렌더러에 추가됩니다.

## 얼마나 가까운가

패스가 두 개면 `자동`, 세 개 이상이면 `자동, 근사`. 그런 오브젝트가 화면에 여러 개 있으면, 각 오브젝트의 처음 두 패스가
어떤 오브젝트의 추가 패스보다 먼저 그려지므로, 겹치는 오브젝트의 정렬이 바뀔 수 있습니다.
