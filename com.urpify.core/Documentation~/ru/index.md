# Urpify

Urpify переносит проект Unity, шейдер или пакет из Asset Store со встроенного конвейера рендера (Built-in Render
Pipeline) на URP. Ещё до каких-либо изменений он показывает всё, что сломает переход, включая то, что ломается без
ошибки. Затем переводит то, что может, делает бэкап каждого изменяемого файла и сравнивает каждую сцену до и после по
снятым кадрам. Любой шаг можно откатить.

Urpify выходит в двух пакетах:

| | Urpify (бесплатный, MIT) | Urpify Pro |
|---|---|---|
| Сканирование проекта, папки, файла или `.unitypackage` | Да | Да |
| Сравнение сцен до и после по снятым кадрам | Да | Да |
| Надёжный запуск Render Pipeline Converter от Unity из окна или командной строки | Да | Да |
| Исправления после конвертера Unity (стекло, Self-Illumin, встроенные материалы, bloom из Post-processing v2, настройки URP Asset, материалы из пакетов) | Да | Да |
| Бэкап и откат | Да | Да |
| Панель шейдера: код, превью в Built-in и URP как есть | Да | Да |
| Перевод своих шейдеров, экранных эффектов, скриптов камер, командных буферов и проекторов | Нет | Да |
| Результат: один файл шейдера для обоих конвейеров (Keep Built-in support) | Нет | Да |
| Экспорт переведённого `.unitypackage` | Только отчёт | Да |
| Командная строка | Сканирование, снимки, сравнение, конвертер Unity и бесплатные исправления | Всё |

## Требования

- Unity 2022.3 LTS (URP 14) или Unity 6000.0 LTS, 6000.3 LTS, 6000.5, 6000.6 (URP 17) — проверенные версии. См. [Версии Unity и URP](urp-version-matrix.md).
- Проект на встроенном конвейере или `.unitypackage`, сделанный для него. URP Urpify устанавливает сам, когда это нужно
  миграции.
- Других пакетов не нужно. Urpify ничего не отправляет по сети, кроме архива шейдера, который вы сами решите отправить
  через `Send report` (см. [вопросы и ответы](faq.md#что-отправляет-send-report)).

## Языки

Окно говорит на английском, 简体中文, 日本語, 한국어, русском, Español, Português (Brasil) и Deutsch. По умолчанию оно
следует языку редактора (Preferences > Languages), а если в Urpify такого языка нет — на английском. Язык меняется в
Project Settings > Urpify > Personal > Language. Заметки конвертеров в отчётах и командная строка остаются на английском.
Эти страницы тоже есть на тех же языках, в соседних папках.
