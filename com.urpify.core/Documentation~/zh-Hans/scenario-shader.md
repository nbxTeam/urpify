# 转换着色器

你编写或维护着色器，想把其中一个迁移到 URP，同时不改动它的公式。

## 打开着色器

以下任一方式都会打开着色器面板：
- 扫描后，在 Urpify 窗口的列表中选中该着色器；
- 在 Project 窗口中右键点击着色器 > Urpify > Analyze；
- 把 `.shader` 文件从 Project 窗口或直接从磁盘拖进 Urpify 窗口。来自磁盘的文件留在原处，不会导入任何内容。

## 阅读代码

**代码** 选项卡左侧显示原始着色器，右侧显示转换后的着色器。改动过的行会被标出；把鼠标悬停在某一行上即可看到改动原因：
为 URP 重新加标签的 Pass、被替换的 Built-in include、为 SRP Batcher 移入 `UnityPerMaterial` 的材质属性。

Urpify 会改什么、不会改什么：
- 着色器名称和属性名称保持不变，因此材质仍能工作并保留其数值。
- 作者的函数（`surf`、`vert`、`frag`、光照函数、辅助函数）原样复制。只有“接线”会变：着色器如何获取光源、阴影、深度、
  屏幕图像和矩阵。
- `UnityObjectToClipPos`、`_LightColor0`、`UNITY_LIGHT_ATTENUATION` 等 Built-in 名称通过 Urpify 的兼容库
  `BirpCompat.hlsl` 继续可用，该库将它们映射到 URP。

**编辑结果** 允许你修改转换后的代码，并用其材质所用的关键字进行 **编译**；错误会显示在对应的行上。**另存为...** 将结果写入
新文件；**转换** 会先把原文件备份到 `Urpify/Backup/ShaderPanel`，再替换它。

当转换器无法完成时，右侧一栏会显示一份只读草稿，标出停止的行和原因。你可以保存草稿再手动完成；“转换”按钮和迁移永远不会
使用它。

## 预览

**预览** 选项卡会在球体、立方体、平面或你自己的网格上，分别用 Built-in 和 URP 渲染该着色器，两者使用相同的材质数值。
**视图** 可在 Built-in、URP、带滑块的帘幕和差异图之间切换。**光照方向** 用于旋转主光源。修改材质属性，两个预览都会随之
更新。

Built-in 预览会在渲染的瞬间关闭渲染管线并再开启，整个过程在一次调用内完成。如果失败，面板会切换到 **来自捕获**，改为
显示场景捕获。对于已经转换过的文件，Built-in 一侧会从迁移的备份中渲染原始着色器。

## 检查结果

迁移转换的每个着色器还会通过渲染进行检查：用项目中使用该着色器的材质贴在一个球体上，转换前在 Built-in 中渲染，转换后在
URP 中渲染。若球体有超过 25 % 的部分不同，着色器仍会被转换，但会被标记为 `检查`，两张图片保存在
`Urpify/Reports/self-check/`。转换后代码无法编译的着色器会被恢复原样并报告。

## 转换停止时

面板会指出转换器无法处理的结构以及该怎么做。[哪些内容不会被转换](not-converted.md) 列出了全部情况。如果某个着色器本应能
转换却没有转换，**报告 > 发送报告...** 会把着色器、它的 include 文件和发现打包成一个压缩包：你可以保存它，或发送给我们
（只有在你点击发送时才会发送）。

## 着色器的许可证

如果文件头中写明了许可证，面板会显示它。转换后的副本仍受同一许可证约束；若是非商业许可证，则不得出售。
