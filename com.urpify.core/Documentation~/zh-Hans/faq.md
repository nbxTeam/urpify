# 常见问题

## 扫描会改动我的项目吗？

不会。扫描只读取文件。只有迁移窗口中明确说明会改动文件的步骤，以及着色器面板中的“转换”按钮会做改动，而且每次都会先备份。

## 我的项目有多少能被转换？

在任何改动之前，扫描就会告诉你：概览按由谁修复来统计损坏的资源。
在开发者未见过的着色器上进行的独立测试中 Urpify 的转换结果，见产品页面。

## 可以撤销迁移吗？

可以。**全部回滚** 会还原迁移改动过的每个文件，并把迁移创建的文件移入备份。迁移后你自己改动的文件，以及在步骤之间出现的
文件，会保持原样并被列出。中断的步骤会像完成的步骤一样回滚。即便如此，开始前仍请提交项目：你最信任的是提交。

## 我需要 Pro 吗？

免费包会找出所有会损坏的内容，可靠地运行 Unity 转换器，修复 Unity 转换器出错的地方，对比迁移前后的场景，并支持回滚。Pro
转换免费包做不到的内容：自定义着色器、图像效果、相机脚本、命令缓冲区和投影器。购买之前，概览就会显示你的损坏资源中有多少
需要 Pro。

## Urpify 会重写我的着色器代码吗？

只改“接线”。作者的函数（`surf`、`vert`、`frag`、光照函数、辅助函数）原样复制；变化的是着色器如何获取光源、阴影、深度、
屏幕图像和矩阵。Built-in 的名称通过 Urpify 的兼容库继续可用。着色器名称和属性名称保持不变，因此材质保留其数值。

## 如果转换后的着色器看起来不对怎么办？

每个转换后的着色器都会用你的材质贴在一个球体上，分别在 Built-in 和 URP 中渲染。如有差异，它会被标记为 `检查`，两张图片
放在 `Urpify/Reports/self-check/`。在着色器面板中打开它：预览选项卡并排显示 Built-in 和 URP，代码选项卡显示每处改动及
原因。你可以在那里编辑结果并重新编译，或随迁移一起回滚该着色器。

## 支持我的 Unity 版本吗？

已在 Unity 2022.3 LTS、6000.0 LTS、6000.3 LTS、6000.5 和 6000.6 上测试；6000.1、6000.2 和 6000.4 未测试。参见 [Unity 与 URP 版本](urp-version-matrix.md)。

## 能在 CI 中使用吗？

可以。每个步骤都可从命令行运行并写出 JSON 结果，参见 [命令行](cli.md)。

## “保留 Built-in 支持”会让构建变大吗？

会大一点。在测试环境（Unity 6.5，Mono）中，游戏数据在 Built-in 下为 32.5 MB，在使用仅 URP 着色器的 URP 下为 38.2 MB，使用
两种管线通用的着色器时为 38.5 MB：多出 0.34 MB，即 0.9 %。

## 转换后的图像效果和投影器在 URP 中开销更大吗？

它们通过 Urpify 的渲染器功能运行，该功能把同样的绘制调用记录到 URP 的帧中。在小场景中，一个投影器每帧约 0.02 ms；有 5000
个可见渲染器时约 2.2 ms。构建出的播放器在 Mono 和 IL2CPP 构建中都保留这些效果。

## “发送报告”会发送什么？

在你点击“发送”之前什么都不会发送。报告 > 发送报告... 会打包所选着色器、它的 include 文件、发现、Unity、URP 和 Urpify 的
版本、编译器错误，以及你填写的话，还包括你的备注和联系方式。发送前窗口会列出每个文件。**发送** 把压缩包上传到我们的支持
渠道；**改为保存 zip** 把它保存在你的电脑上。这些文件只用于了解转换器还缺什么，之后即被删除。这是 Urpify 中唯一的网络
调用。每分钟最多发送一份报告。

## 我可以出售 Urpify 转换过的着色器吗？

可以，遵循它们各自的许可证。参见 [再分发转换后的着色器](../license-redistribution.md)（英文）。文件头声明了非商业许可证的
着色器仍受该许可证约束；着色器面板会显示许可证那一行。

## 为什么扫描说我的项目在迁移前就已损坏？

因为确实如此：在 Built-in 中无法编译的着色器、无法编译的脚本、项目中不存在的 include 文件、项目中不存在的材质。Urpify 把
它们单独列出，因为迁移无法修复它们。请先修复，然后重新扫描。

## 回滚 URP 后，着色器会显示一次 include 错误。为什么？

从曾经安装过 URP 的项目中移除 URP 后（回滚或手动还原），第一次编辑器会话仍可能编译用“保留 Built-in 支持”生成的着色器中
的 URP SubShader，并因 `Library/Artifacts` 中残留的导入结果而记录 include 错误。第二次会话时这些错误就消失了。这是 Unity
的导入行为，而不是着色器文件的问题：在从未安装过 URP 的项目中不会出现错误。请再打开一次项目，或运行 Assets > Reimport All。

## 窗口显示的是其他语言。

Project Settings > Urpify > 个人 > 语言。默认跟随编辑器语言，若 Urpify 没有该语言则使用英语。
