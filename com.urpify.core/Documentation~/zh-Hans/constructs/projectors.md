# 投影器

![展台 C01：投影器投下的阴影斑，经 Unity 转换器后消失，经 Urpify 后恢复](../../images/C01.jpg)

*展台 C01：`Projector` 组件在立方体下方投下一块阴影斑。只经过 Unity 转换器时，没有阴影。*

## 什么会损坏

URP 不渲染 `Projector` 组件。阴影斑、选择圈和投影贴花会在没有任何提示的情况下消失。

发现：“... 上的 Projector”（`SCENE.PROJECTOR`）、“投影器着色器”（`SHADER.PROJECTOR`）。

## Urpify 的做法（Pro）

`Projector` 仍是投影器，其着色器保持不变。Urpify 的 Built-in Camera Hooks 渲染器功能把每个启用的投影器的材质绘制到其视锥
和图层内的渲染器上，并像 Built-in 一样为每个物体设置 `unity_Projector` 和 `unity_ProjectorClip`。尺寸、朝向、范围、忽略的
图层和材质都取自组件，因此你可以像以前一样编辑投影器。

该功能缓存投影器及其能照到的渲染器，而不是每帧搜索场景：投影器每 30 帧更新一次，渲染器每 60 帧更新一次，加载或卸载场景
时两者都会更新。渲染器会按每个投影器和相机的视锥进行剔除。在 Unity 6.5 上用一个投影器测量：88 个渲染器时每帧 0.02 ms；
再增加 5000 个渲染器时，若全部在相机前方约 2.2 ms，在相机后方则为 0.09 ms。

由于投影器和它的着色器都没有任何变化，用“保留 Built-in 支持”导出的包在两种管线中都能继续工作。

## 有多接近

`自动（近似）`：同样的着色器作用于同样的物体。不使用 URP 自己的 Decal Projector，因此外观保持 Built-in 的样子。
